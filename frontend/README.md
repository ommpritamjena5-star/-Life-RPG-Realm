# ⚔️ Life RPG — Frontend Client

The React 19 + Vite + Tailwind CSS client for **Life RPG** (Gamified Personal Operating System).


## 🛠️ Tech Stack
- **React 19** with Vite 8
- **Tailwind CSS v4** + Custom Dark Fantasy Theme & Glassmorphism
- **Three.js** 3D Interactive Starfields & 3D Character Models
- **Framer Motion** Micro-animations & Particle physics
- **Web Audio API** Dynamic Synthesized RPG Soundscapes (Level-up, Chimes, Rain Ambience)
- **Lucide Icons**
